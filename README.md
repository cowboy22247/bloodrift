# 血裂隙 Bloodrift

十分鐘一局的暗黑風倖存者。撿到的裝備，要活著回城才算你的。
免費、免安裝，電腦和手機瀏覽器都能玩。

**線上玩：** （部署後自動填入）

## 操作
- 移動：WASD／方向鍵；手機：左半邊搖桿
- 主動技：空白鍵　回城符：T　戰利品包：B　暫停：Esc
- 升級與拾取比較卡：按 1–4

## 特色
- 三個職業（野蠻人、女巫、死靈法師）、兩張地圖、四個首領
- 30 個會改變技能的傳奇特效、16 種精英詞綴
- 裝備要活著回城（或用回城符）才帶得回倉庫，死亡會隨機掉一半

## 素材與致謝
- 角色模型：KayKit Adventurers / Skeletons character packs（CC0）
- 場景素材：本機 AI 生成（Qwen-Image-Edit）
- 遊戲設計與程式：作者本人
